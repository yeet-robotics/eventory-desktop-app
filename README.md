# Eventory Desktop

Ticket alerts that reach you with every browser tab closed.

## Download

**[Download the latest release](https://github.com/yeet-robotics/eventory-desktop-app/releases/latest)**

- **macOS** — one `.dmg` for both Apple Silicon and Intel. Open it and drag
  Eventory to Applications. Requires macOS 11 or later.
- **Windows** — coming shortly.

## What it does

Eventory sits in your menu bar and holds the connection to your monitors
itself. Restocks, price changes and stock drops arrive as native notifications
— with sound, and clickable straight through to the event. Close the tab, quit
Chrome, lock the machine: the alerts still land.

It launches with your computer, and updates itself. Closing the window leaves
it running in the menu bar; quit it from there when you want it to stop.
